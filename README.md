# Universo Herois 🦸
Projeto de banco de dados desenvolvido com MySQL, criado para organizar informações sobre heróis e equipes dos universos Marvel e DC.

O projeto faz parte dos meus estudos em Análise e Desenvolvimento de Sistemas, com foco em modelagem de banco de dados, relacionamentos entre tabelas e consultas SQL.

🗄️ Banco de Dados

Atualmente, o projeto conta com informações relacionadas a:

Heróis
Universos Marvel e DC
Equipes
Relacionamento entre heróis e equipes
Níveis de poder
Habilidades e identidades dos personagens
